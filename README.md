# WinDeck

Windows 10 / 11 全局窗口切换器与虚拟桌面调度中心，灵感来自 macOS Mission Control。使用 **Rust + GPUI + 原生 Win32 / DWM / COM** 构建，单文件零外部运行库依赖。

## 主要特性

- **全景实时缩略图**：一屏总览所有虚拟桌面上的窗口实时画面（DWM 硬件合成 + 真实 Acrylic 高斯模糊），支持铺满裁剪（Cover）与完整等比（Contain）一键切换。
- **按住主键快切**：全局快捷键格式为 `(Ctrl | Alt | Win) + <A-Z>`（默认 `Alt+Q`）。按住主键并敲击方向键选窗，松开主键即刻跳转；短按松开则停留在面板内自由浏览。
- **顶部虚拟桌面胶囊栏**：单击过滤桌面、双击直切桌面、`+` 新建虚拟桌面、右键桌面标签切换为红色垃圾桶确认关闭（窗口自动安全迁移至相邻桌面）。
- **可配置转场特效**：支持在设置面板中配置「转场特效」四档风格（关闭 / 轻盈 / 流畅 / 灵动），并可独立开关顶部桌面标签过渡（FLIP 滑移 + 交叉淡入淡出）、焦点框与平滑滚动、以及切窗放大飞向目标位置与切桌面转场。
- **快捷键强制退出**：在切换器内悬停或选中目标窗口，按下强制退出快捷键（默认 `Delete`，可在设置中改为任意键或组合键）即可关闭或强杀无响应窗口（自动保护 `explorer.exe` 等系统外壳进程，并正确识别 UWP 宿主进程）。
- **极简毛玻璃设置与自动更新**：右下角入口或托盘菜单进入；支持配置自动检查 GitHub Releases 新版本、弹窗确认并自动校验 SHA-256 完成原地替换与重启。
- **轻量常驻**：单实例互斥锁、系统托盘开机自启开关、隐藏驻留期间近零 CPU 占用。

## 下载与使用

前往 [Releases](https://github.com/akirousnow/windeck/releases/latest) 下载单文件 `windeck.exe`，双击即可运行（无需安装运行库）。

> [!NOTE]
> 首次运行未签名可执行文件时，Windows SmartScreen 可能会弹出「Windows 已保护你的电脑」提示，点击「更多信息」→「仍要运行」即可。

### 常用快捷键

| 按键 | 功能 |
| :--- | :--- |
| `Alt+Q`（可自定义） | 呼出 / 收起 WinDeck；按住主键 + 方向键松手自动跳转 |
| `←` `→` `↑` `↓` / `Tab` | 跨虚拟桌面网格选窗 |
| `Enter` / `Space` / 左键点击 | 跳转到选中窗口 |
| `Delete`（可自定义） | 强制退出悬停或选中的窗口 |
| `F` | 实时切换预览适配（铺满裁剪 / 完整等比） |
| `L` | 实时切换应用标签位置（右下 / 左下 / 居中 / 下方） |
| `-` / `=` | 实时微调毛玻璃暗度 |
| `Esc` / 点击空白 | 取消状态或隐藏切换器 |

### 系统要求

- **Windows 11（21H2 / 22H2 / 23H2 / 24H2 / 25H2 / 26H1，x64）**：支持完整跨虚拟桌面切换与增删桌面。
- **Windows 10（1903–22H2，x64）**：支持窗口缩略图预览与虚拟桌面切换；未知未来内部版本将自动降级为只读桌面枚举，不会崩溃。

配置文件与日志位于 `%APPDATA%\WinDeck\`。

## 从源码构建

需要 Rust 工具链（Edition 2024）与 Windows 10/11 SDK（含 `rc.exe`）：

```powershell
cargo build --release -p windeck
```

编译产物位于 `target\release\windeck.exe`。
